# 02 — 미완성 기능 목록

> 우선순위: P1(기능 결함) > P2(운영 필수) > P3(개선). 각 항목의 실행 지시는 `05-work-orders.md` 참조.

## P1 — 스키마에 있으나 동작하지 않는 것

### 1. `scheduled` 상태가 예약 발행으로 동작하지 않음
- 근거: `posts.ts` `getPublishedPosts()`는 `status === 'published'`만 노출. `scheduled` 글은
  발행일이 지나도 영원히 비공개.
- 어드민 편집기의 상태 옵션 설명("발행일 이후 공개")과 실제 동작이 불일치.
- 참고: 예약 발행에는 `publishedAt`(예약 시각) 입력 UI도 없음 — `savePostAction`은 published 전환
  시에만 자동 스탬프.

### 2. 검수 완료 글의 발행 대기
- `결정적-콘텐츠-검수-게이트`가 `in_review` 상태. 사람 검수·발행 필요(하드 룰 2 — 에이전트/Claude가
  발행하면 안 됨). 커버 이미지도 없음(`image-maker` 위임 또는 이미지 없이 발행 가능).

### 3. FAQ/인용/hreflang 반복 필드의 확장 한계
- 편집기가 클라이언트 JS 없이 빈 행 2개(`EXTRA_ROWS = 2`)만 미리 렌더 → 저장 한 번에 최대 2개씩만
  추가 가능. 의도된 트레이드오프지만 UX 미완성으로 분류.

## P2 — 운영 전 필수

### 4. 어드민 인증 없음
- `:3001` 전체(편집·삭제·발행 버튼 포함)가 무인증. 로컬 데모는 무방하나 배포 시 치명적.
- 최소한 Basic Auth 미들웨어 또는 "배포 금지, 로컬 전용" 명시 필요.

### 5. 테스트 0개
- `turbo test` 태스크는 정의됐지만 어느 워크스페이스에도 test 스크립트/테스트 파일 없음.
- 최우선 대상: `auditPost()`(발행 게이트 — 결정적이라 테스트 적합), `schema.ts` 파싱, `slugify`,
  file 드라이버 round-trip.

### 6. Supabase 드라이버 미검증
- `repo/supabase.ts` + 마이그레이션 + 이관 스크립트는 존재하나, 키 없는 데모 상태라 실 DB 경유
  경로(getAll/save/remove, Storage 업로드, RLS)가 한 번도 검증되지 않았을 가능성. 문서상으로도
  검증 기록 없음.

### 7. lint 체계 불일치
- 앱은 `next lint`(Next.js 16에서 제거 예정 계보), 패키지 2개는 "no linter configured" 에코.
  ESLint flat config 또는 Biome로 통일 필요.

## P3 — 개선 후보

### 8. 웹 검색/페이지네이션 없음
- 글이 수십 편 이상이면 목록·홈 모두 전체 렌더. 태그 필터만 존재.

### 9. `archived` 상태의 표면적 처리
- 비공개 처리만 되고, 어드민 목록에서 구분 필터·숨김이 없음.

### 10. `getPublishedPosts()`가 noindex 글을 사이트에서 완전히 제외
- noindex(색인 제외)와 사이트 비노출이 결합돼 있음. "색인은 막되 URL 접근은 허용" 케이스 불가.
  의도라면 wiki에 근거 기록, 아니라면 분리.

### 11. 카테고리 미노출
- frontmatter `category`는 저장·감사되지만 web에 카테고리 페이지/표시 없음.

### 12. 어드민 에러 UX
- 서버 액션이 `throw new Error(...)` — 프로덕션 빌드에선 일반화된 에러 화면. 폼 인라인 에러 표시 없음.

### 13. OG 이미지 자동 생성 없음
- 커버 없는 글은 OG 이미지도 없음. (주의: 동적 OG 생성 시에도 하드 룰 1 검토 — `next/og` 텍스트
  카드가 "이미지 생성"에 해당하는지 ADR-0002 관점 판단 필요.)

### 14. 작업 로그의 미완료 항목

  미수행. 해당 글에 대한 감사 실행·기록 필요.
