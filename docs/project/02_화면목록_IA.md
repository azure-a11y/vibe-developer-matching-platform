## 왜 지금 확정할 수 없는가

**Q18(1안/2안 디자인 통합 방향)이 미해결**이다. `CLAUDE.md` "멀티에이전트 작업 원칙"상 이 결정은
한 명의 책임 주체가 내려야 하고, 화면 구조(IA)는 그 결정에 종속된다. 1안(`artifact/builder-group`,
인터랙션·소구점 우수)과 2안(에셋 퀄리티·Eduinfo 별도 페이지 보유)은 섹션 순서·페이지 분할 방식이
다를 수 있어, 통합 전에 IA를 확정하면 통합 후 다시 그려야 한다.

빌더 프로필(FR-7)이 별도 최상위 화면인지 Work 상세 모달에 흡수되는지도 **Q17 미확정** — 이 역시
화면 트리 자체를 바꾸는 결정이라 IA보다 먼저 풀려야 한다.

## 지금 확인 가능한 것 (참고용, 확정 아님)

목업(`artifact/builder-group`) 기준 실제 구현된 섹션 순서:

```
Hero → Work → Insight → Eduinfo → FAQ → About → Related Links → Footer
```

관리자(`artifact/admin` 시안) 메뉴 트리:

```
대시보드 / Builder / Work / Work Process / Insight / 설정 / 계정·권한
```
