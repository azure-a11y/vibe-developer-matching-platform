## 1. 제품 정의와 성공 판정

### 1.1 한 줄 정의

> **AI 시대에 최적화된 고품질 바이브코딩 외주 전문 브랜드의, 수주용 랜딩 페이지 및 관리 운영 플랫폼**

이 제품의 유일한 사업 목적은 **발주 리드를 pluug에 적재하는 것**이다. 교육 홍보도, 3사 소개도, 회원 확보도 목적이 아니다.

### 1.2 성공 조건 — 판정 가능한 형태로 재정의

기획서 §1.1의 성공 조건 2개는 정성적이다. **검수에서 다투지 않으려면 판정 기준이 숫자·체크리스트여야 한다.**

| # | 성공 조건 | **판정 방법 (검수 시 이대로 확인)** | 판정자 |
|---|---|---|---|
| **①** | "AI로 딸깍한 느낌"이 나지 않는 디자인 | ⓐ 홈 10개 섹션의 인터랙션 유형이 **인접 섹션 간 100% 상이**<br>ⓑ **무애니메이션 섹션이 정확히 2개**(S4·S7) 존재<br>ⓒ 카드 컴포넌트가 섹션별로 **동일 반복되지 않음**(최소 3종)<br>ⓓ `prefers-reduced-motion` 시 전 인터랙션이 페이드 1종으로 대체 | 리드 2인 |
| **②** | 전환 개선이 가능한 데이터 트래킹 구조 | ⓐ §8.2 **이벤트 7종 전부** GA4 DebugView에서 발화 확인<br>ⓑ FAQ 토픽·목록 필터 전환 시 **URL이 실제로 변경**되고 `page_view`가 재발화<br>ⓒ `/submit` 도달이 `contact_submit`으로 기록되고 **직접 방문은 필터링**됨<br>ⓓ `/content` 외부 링크 전수에 UTM 부착 | 리드 2인 |

> 두 조건은 **AND**다. ①만 만족하면 오픈 후 개선 근거가 없고, ②만 만족하면 기획서 §1.1 기준으로 탈락이다.

### 1.3 제품 KPI (오픈 후 측정) 🟡

| # | 지표 | 정의 | 목표 |
|---|---|---|---|
| K1 | 문의 제출 수 | `contact_submit` 이벤트 수 / 월 | ❓ 클라이언트 확정 전 공란 |
| K2 | 문의 제출률 | K1 ÷ 세션 수 | ❓ 공란 (베이스라인 4주 후 설정) |
| K3 | Insight→문의 전환율 | `insight_detail_view` 세션 중 `contact_submit` 도달 비율 | ❓ 공란 |
| K4 | 콘텐츠→유튜브 이동 | `youtube_outbound` 수 (유튜브 스튜디오 UTM과 교차 검증) | ❓ 공란 |

> **목표 수치를 임의로 채우지 않는다** (기획서 C5). 오픈 후 4주 베이스라인을 측정해 클라이언트와 함께 설정한다.

## 2. 사용자와 권한

### 2.1 사용자 유형

| 코드 | 사용자 | 인증 | 이 제품에서 하는 일 | 성공 종착점 |
|---|---|---|---|---|
| **U1** | 발주 담당자 (기업·스타트업) | 무인증 | 탐색 → 검증 → 문의 | `/submit` 도달 |
| **U2** | 잠재 발주자 (검색·유튜브 유입) | 무인증 | Insight·콘텐츠 열람 | U1로 전환 |
| **U3** | **빌더** (수료생) | 로그인 | 본인 Work·Insight 등록 → 승인 요청 | 콘텐츠 발행 |
| **U4** | **운영 관리자** | 로그인 | 콘텐츠 CRUD·승인·계정 관리 | 사이트 운영 |
| — | 크몽 영업사원 | — | **사이트 밖(pluug)에서 리드 확인** | 범위 밖 |

> 🔒 **일반 고객 회원가입·로그인은 만들지 않는다**(E5). 로그인이 존재하는 유일한 이유는 U3·U4의 콘텐츠 운영이다.

### 2.2 권한 매트릭스 🟡 — **구현 기준**

| 대상 | 운영 관리자(U4) | 빌더(U3) | 비로그인 |
|---|---|---|---|
| Insight 목록·편집 (A-02·A-03) | 전체 CRUD + **발행** | **본인 글만** C·R·U (발행 불가, 제출만) | ❌ |
| Work 목록·편집 (A-04·A-05) | 전체 CRUD + **발행** | **본인 프로젝트만** C·R·U (발행 불가, 제출만) | ❌ |
| 빌더 관리 (A-06) | 전체 CRUD + 발급·회수 | **본인 프로필만** 수정 | ❌ |
| 승인 대기 (A-07) | **승인·반려** | ❌ (접근 시 403) | ❌ |
| 공개 페이지 (P-01~P-10) | 열람 | 열람 | 열람 |

**권한 판정 규칙**
- 권한 검사는 **서버에서 한다.** UI 숨김만으로 처리하지 않는다 (숨겨도 URL 직접 입력이 가능하다).
- 타인 리소스 접근 시 **404가 아니라 403**을 반환한다 — 단, 존재 여부 노출이 문제되는 필드는 없으므로 403으로 통일.
- 관리자 승격은 **DB 직접 변경으로만** 가능하다. 화면에서 관리자를 만들 수 없다.

### 3.2 릴리스 게이트 (Definition of Done)

**아래를 전부 통과해야 오픈이다.** 하나라도 미충족이면 오픈일을 옮기거나, 미충족 항목을 리스크로 명기하고 클라이언트 서면 동의를 받는다.

| # | 게이트 | 판정 |
|---|---|---|
| G1 | P0 요구사항 **전건** 통과 | §15 ID 색인의 P0 전수 체크 |
| G2 | 성공 조건 ①·② 판정 (§1.2) | 리드 2인 서명 |
| G3 | 반응형 3종(모바일·태블릿·데스크톱) 전 화면 깨짐 없음 | §11.1 기기 목록 |
| G4 | Lighthouse 모바일 **성능 ≥ 85 / 접근성 ≥ 95 / SEO = 100** (홈·Work 상세·Insight 상세) | 3개 대표 페이지 |
| G5 | SEO 산출물 4종(sitemap·robots·llms.txt·JSON-LD) 실제 응답 확인 | §9 |
| G6 | pluug 제출 → `/submit` 도달 **E2E 1회 실증** | §10.1 |
| G7 | 관리자 전 화면 권한 우회 시도 실패 확인 (빌더 계정으로 A-06·A-07 접근) | §2.2 |
| G8 | 이관 체크리스트 완료 (계정·권한·환경변수·하자보수 접근권) | 3주차 |

> ⚠️ **G6가 미충족이면 전환 측정이 성립하지 않는다** = 성공 조건 ② 실패. pluug 권한을 3주차까지 못 받으면 **"제출 완료 전환 측정 불가"를 리스크로 명기하고 오픈**한다(기획서 R3).

### 7.3 콘텐츠 상태 머신 🟡 — **works·insights 공통**

```
초안(draft) ──제출──> 승인대기(pending) ──승인──> 발행(published) ──내림──> 보관(archived)
    ↑                        │                                              │
    └──────반려(rejected)────┘                                              │
    └──────────────────────────수정──────────────────────────────────────────┘
```

| 상태 | 공개 노출 | 편집 주체 | 사이트맵 | 전이 가능 |
|---|---|---|---|---|
| `draft` | ❌ | 작성자 | ❌ | → pending |
| `pending` | ❌ | **잠금**(작성자 편집 불가) | ❌ | → published(관리자) / → rejected(관리자) |
| `published` | ✅ | 관리자 | ✅ | → archived |
| `rejected` | ❌ | 작성자 (+사유 표시) | ❌ | → draft → pending |
| `archived` | ❌ | 관리자 | ❌ (**301 처리**) | → published |

| ID | 요구사항 | 우선 | 인수 조건 |
|---|---|---|---|
| **DR-06** | 위 표에 없는 상태 전이는 **서버에서 거부**한다 | P0 | 빌더의 published 직행 시도 403 |
| **DR-07** | `pending` 상태는 작성자가 편집할 수 없다 | P0 | 제출 후 잠금 |
| **DR-08** | `archived` 전이 시 해당 URL은 **301**로 처리한다 (404 아님) | P0 | 색인 손실 방지 |

| **D3** | **미리보기 URL의 보안 수준** | 승인 전 콘텐츠가 링크 유출로 공개될 수 있음 | **인증 필수 미리보기**(공개 토큰 URL 금지) |
| **D4** | **빌더 계정 회수 시 콘텐츠 처리** | 수료생 이탈 시 발행 글이 사라지면 사이트에 구멍이 난다 | **콘텐츠 유지 + 계정만 비활성**(FR-A06-03) |
