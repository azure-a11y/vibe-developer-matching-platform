## 토픽 구성 🟡 (초안 — 콘텐츠 확정 시 조정)

| 토픽 | URL | 다루는 질문 |
|---|---|---|
| 외주 문의 | `/faq/inquiry` | 품질·기간·비용 문의 방법·계약 |
| 진행 방식 | `/faq/process` | 단계·검수·수정·유지보수·이관 |

- `/faq` 접근 시 → `/faq/inquiry`로 리다이렉트 (기본 토픽)
- **기본 토픽 순서는 GA 데이터로 재조정한다** — "사용자가 계속 두 번째 탭을 클릭하면 순서를 바꿔야 한다"는 실측 원칙 적용

## 스펙

| 항목 | 내용 |
|---|---|
| 아코디언 | 높이 전개 애니메이션. `aria-expanded` + `aria-controls` 필수. 동시 여러 개 열림 허용 |
| 이벤트 | 토픽 전환 `faq_topic_change {topic}` (URL 분기와 이중 기록) |
| ⛔ 금지 | FAQ 옆 다운로드·소개서 버튼 — **문의 전환을 0으로 만든 실측 사례** |
| SEO | JSON-LD: FAQPage (질문·답변 구조화) — 검색 결과 리치 스니펫 노출 |
| 데이터 | 1차: 정적 데이터로 구현 (관리자 FAQ CRUD는 백로그 — 03-백로그 참조) |

## 모바일

- 토픽 탭 그대로 유지 (2개라 문제없음).
- 아코디언 터치 영역 최소 44px.
