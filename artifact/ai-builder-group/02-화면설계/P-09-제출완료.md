# P-09 제출 완료 `/submit`

| | |
|---|---|
| 우선순위 | **P0** — 이 페이지 도달 = 전환. 사이트 전체 KPI의 측정 지점 |
| 색인 | ❌ **noindex + sitemap 제외** (직접 유입되면 가짜 전환) |
| 진입 경로 | pluug "제출 후 이동 링크" 설정으로만 도달 |

## 스펙

| 항목 | 내용 |
|---|---|
| **전환 이벤트** | 도달 시 `contact_submit` 발화 — **GA4 전환 지표로 지정** |
| 가짜 전환 방어 | `referrer`가 pluug 도메인(또는 자체 폼 경로)이 아니면 이벤트 미발화. 또는 `/submit?src=pluug` 토큰 방식 — 구현 시 택일 |
| 체크 아이콘 | 등장 시 1회 마이크로 애니메이션 (원 그리기). 이후 정지 |
| 추천 콘텐츠 | Insight 최신 1건 + 유튜브 채널 링크(UTM). **문의 완료자를 그냥 보내지 않는다** |
| noindex | `<meta name="robots" content="noindex">` + sitemap 제외 + robots.txt 차단은 하지 않음(리다이렉트 도달 허용) |
| GNB | 유지하되 [문의하기] CTA는 이 페이지에서만 숨김 (이미 문의함) |
