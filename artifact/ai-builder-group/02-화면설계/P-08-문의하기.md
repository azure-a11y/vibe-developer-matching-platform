## B안. pluug 직링크

```
│   프로젝트 문의 (H1)                                           │
│   하루 안에 담당자가 연락드립니다                              │
│                                                                │
│   진행 순서: ① 접수 → ② 배정 → ③ 상담·견적 → ④ 착수           │
│                                                                │
│              ┌──────────────────────────┐                      │
│              │   문의 작성하러 가기 →   │  ← pluug 폼으로 이동 │
│              └──────────────────────────┘                      │
│                                                                │
│   이메일로 문의하기: contact@_____                             │
```

## 두 안의 트레이드오프 (8/12 미팅 제시용)

| | A안 임베드 | B안 직링크 |
|---|---|---|
| 이탈률 | **낮음** (도메인에 머묾) | 높음 (도메인 이탈) |
| 구현 | iframe 리다이렉트 처리 한 단계 추가* | **단순** |
| 제출 측정 | 가능* | **확실** (`/submit` page_view) |
| 색인 | iframe 내부 색인 안 됨 | 페이지 자체는 색인됨 |

\* 임베드 시: pluug "제출 후 이동 링크"가 iframe 안에서 열리면 `postMessage`로 부모에 알리거나 최상위 프레임 이동으로 설정.

## 공통 스펙

| 항목 | 내용 |
|---|---|
| 제출 후 | pluug "제출 후 이동 링크" → **우리 도메인 `/submit`** (P-09). 이것이 전환 측정의 성립 조건 |
| 폼 필드 | pluug 폼에서 설정 (우리 DB 저장 ⛔). 필드 구성은 위 목업이 제안 초안 |
| 개인정보 동의 | pluug 폼 기능으로 처리. `/privacy` 링크 연결. 문안은 클라이언트 승인 후 |
| 안내 카피 | 응답 기준("하루 안에")은 클라이언트 합의 후 확정 — 그전까지 "빠르게 연락드립니다" |
| 인터랙션 | ⛔ 없음. 전환 페이지에서 시선을 뺏는 요소 금지 |
| 이벤트 | 진입은 `/contact` page_view로 충분 (모달 아님 — `?contact=true` 불필요) |
| 유입 맥락 | 🟡 Work 상세에서 진입 시 `?ref=<slug>` 파라미터로 관심 프로젝트 전달 (pluug 폼 히든 필드 매핑 가능 여부는 Q5와 함께 확인) |

## 모바일

- 안내 영역을 폼 위로 (진행 순서 4단계는 가로 아이콘 행으로 압축).
