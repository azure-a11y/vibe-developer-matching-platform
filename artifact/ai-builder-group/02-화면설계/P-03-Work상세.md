## 스펙

| 항목 | 내용 |
|---|---|
| 본문 구조 | **문제 → 해결 → 결과** 3막 고정. "일하는 방식" 소구와 정합 |
| 인터랙션 | 히어로 이미지 진입 시 페이드 + 본문 이미지 지연 로드. 과한 스크롤 연출 ⛔ (읽는 페이지) |
| 참여 빌더 | 1차: 이름·역할 칩 표기만. 프로필 링크는 2차 (Q6). ❓ 노출 수위는 Q4·NDA 확정 후 |
| 성과 수치 | 근거 자료 수령 전까지 서술형으로만. 임의 수치 ⛔ (C5) |
| 관련 프로젝트 | 같은 카테고리 최신 3건. 없으면 섹션 숨김 |
| CTA | 하단 배너 1개만. `cta_click {location: "work_detail"}` |
| 이벤트 | 진입 시 `work_detail_view {slug, category}` |
| SEO | OG 이미지 = 히어로 이미지 / JSON-LD: BreadcrumbList / 슬러그 변경 시 301 필수 |
| 이전·다음 | ⛔ 넣지 않음 — 탐색은 관련 프로젝트와 목록으로 충분 |

## 모바일
