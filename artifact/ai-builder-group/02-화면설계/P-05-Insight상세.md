## 스펙

| 항목 | 내용 |
|---|---|
| 본문 폭 | 최대 720px — 가독 우선 |
| 인터랙션 | ⛔ 본문 애니메이션 없음. TOC 현재 위치 하이라이트만 |
| TOC | 본문 h2 자동 추출. h2 2개 미만이면 숨김. 모바일에선 접이식 |
| 영상 임베드 | 유튜브 iframe 지연 로드(퍼사드 패턴 — 썸네일 클릭 시 로드). 임베드 하단 "유튜브에서 보기" 링크에 **UTM 부착** |
| canonical | **자체 작성 글에 외부 canonical ⛔** (색인 이탈 방지 — 기획서 §5.3). 외부 원문이 있는 글만 원본 URL로 canonical |
| 함께 읽기 | 같은 카테고리 최신 2~3건. 없으면 숨김 |
| CTA | 하단 배너 1개. `cta_click {location: "insight_detail"}` |
| 이벤트 | 진입 시 `insight_detail_view {slug, category, author_type}` / 임베드 외부 이동 시 `youtube_outbound` |
| SEO | JSON-LD: Article (headline·datePublished·author) / OG 이미지 = 대표 이미지 |
| 본문 h1 | ⛔ Tiptap에서 h1 차단 (페이지 제목이 h1) — 관리자 편집기 스펙과 세트 |

## 모바일

- TOC → 본문 상단 접이식 "목차 ▾".
- 본문 이미지 풀블리드, 표는 가로 스크롤 컨테이너.
