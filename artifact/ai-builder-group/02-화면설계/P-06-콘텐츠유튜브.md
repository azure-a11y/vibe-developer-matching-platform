## 스펙

| 항목 | 내용 |
|---|---|
| 클릭 동작 | 🟡 **유튜브 직행 + UTM** (사이트 내 상세 페이지 없음 — 기획서 §5.4 권고). 새 탭 열기 |
| UTM 규격 | `?utm_source=builder-group&utm_medium=content&utm_campaign=<영상주제>&utm_content=<featured\|grid\|subscribe>` |
| 이벤트 | 카드·배너 클릭 시 `youtube_outbound {video_id, utm_campaign}` |
| 인터랙션 | 썸네일 hover 시 **화면 전환 퍼짐 프리뷰**(살짝 확대 + 재생 아이콘 강조). 홈 S8과 동일 계열 |
| 콘텐츠 소스 | 이솝 님 유튜브 + 빌더스쿨 수업 콘텐츠. 관리자에서 URL·제목·썸네일 등록 (자동 연동 ⛔ — 범위 절제) |
| 피처드 | 관리자가 1건 지정. 미지정 시 최신 영상 |
| 빈 상태 | "영상을 준비 중입니다" + 유튜브 채널 직링크 |
| SEO | 색인은 허용하되 주력 아님. JSON-LD: VideoObject는 2차로 이관 |

## 모바일

- 피처드 포함 전부 1열.
- hover 프리뷰 제거 — 즉시 이동.
