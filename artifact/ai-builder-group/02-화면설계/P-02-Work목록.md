## 스펙

| 항목 | 내용 |
|---|---|
| 카드 인터랙션 | hover 시 썸네일 미세 줌 + 제목 색 변화 (홈 S6과 달리 목록에선 절제) |
| 등장 | 최초 로드 시 Fade-in 스태거 1회만. 필터 전환 시 애니메이션 없이 즉시 교체 |
| 필터 | 단일 선택. **선택 시 URL 쿼리 반영** (`?category=`) — GA 카테고리별 유입 측정 |
| 정렬 | 발행일 내림차순 고정. 정렬 UI ⛔ (범위 제외 E8) |
| 검색 | ⛔ (범위 제외 E8) |
| 카드 데이터 | 썸네일 / 카테고리 / 제목 / 한 줄 요약 / 참여 빌더 수 🟡(Q4·Q6 확정 전 표기 보류 가능) |
| 페이지네이션 | "더 보기" 버튼 방식 (무한 스크롤 ⛔ — Footer 접근성) |
| 이벤트 | 카드 클릭 → 상세 이동 (`work_detail_view`는 상세에서 발화) |
| SEO | H1에 서술형 키워드. 카테고리 필터 URL도 색인 허용 |

- 썸네일 비율 유지(16:9), 줌 인터랙션 제거.
