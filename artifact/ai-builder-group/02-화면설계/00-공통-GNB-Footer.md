## 1. GNB (Global Navigation Bar)

### 데스크톱 (≥1024px)

```
┌────────────────────────────────────────────────────────────────────┐
│  [로고: AI 빌더 그룹*]        Work   Insight   콘텐츠   [문의하기] │  h=72px
└────────────────────────────────────────────────────────────────────┘
   * 브랜드명 미확정(Q1) — 로고는 교체 가능한 컴포넌트로
```

### 모바일 (<768px)

```
┌──────────────────────────────┐
│ [로고]              [☰ 메뉴] │  h=56px
└──────────────────────────────┘
  ☰ 탭 시 풀스크린 오버레이:
┌──────────────────────────────┐
│ [로고]                  [✕]  │
│                              │
│   Work                       │
│   Insight                    │
│   콘텐츠                     │
│                              │
│  ┌────────────────────────┐  │
│  │      문의하기 →        │  │ ← 하단 고정 CTA
│  └────────────────────────┘  │
└──────────────────────────────┘
```

### 동작 스펙

| 상태 | 동작 |
|---|---|
| 최상단 (scrollY = 0) | 배경 투명, 로고·메뉴 기본색 |
| 스크롤 시 | 배경 블러+반투명 흰색, 하단 1px 보더. **높이는 변경하지 않는다** — "헤더가 넓어지는 동작이 정말 좋은 UX인가"는 검토 결과 채택 안 함 (기획서 §6.1) |
| 현재 페이지 | 해당 메뉴에 언더라인 표시 |
| [문의하기] | 버튼형(필 컴포넌트). `cta_click {location: "gnb"}` 이벤트 |

- ⛔ **관리자 링크를 넣지 않는다.**
- ⛔ **드롭다운 없음.** 메뉴 4개가 전부 — 1 depth 유지.

## 2. Footer

```
┌────────────────────────────────────────────────────────────────────┐
│  [로고]                                                            │
│  AI 시대에 최적화된 바이브코딩 외주 전문 그룹  ← 한 줄 소개        │
│                                                                    │
│  Work        Insight       콘텐츠        문의하기                  │
│                                                                    │
│  ──────────────────────────────────────────────────────────        │
│  문의: contact@_______ ← ★ pluug 장애 대비 대체 경로(이메일 미정) │
│  개인정보처리방침  |  ⓒ 2026 AI 빌더 그룹                          │
│  사업자 정보 (상호·대표·사업자번호 — 자료 수령 후 기입)            │
└────────────────────────────────────────────────────────────────────┘
```

| 항목 | 스펙 |
|---|---|
| 이메일 | **필수.** pluug 단일 장애점 대비 대체 연락 경로. 주소는 클라이언트 확인 필요 |
| 개인정보처리방침 | `/privacy` 링크. 문안 미수령이어도 **링크 자리는 오픈일에 있어야 함** |
| 애니메이션 | ⛔ 없음 |
| ⛔ 금지 | "소개서 다운받기"류 버튼 — 전환을 죽인 실측 사례 (기획서 §7.3) |

## 3. 공통 CTA 정책

| 위치 | 형태 | `location` 파라미터 |
|---|---|---|
| GNB 우측 | 필 버튼 | `gnb` |
| 홈 Hero (S1) | 대형 버튼 | `hero` |
| 홈 최종 섹션 (S10) | 대형 버튼 | `footer_cta` |
| Work 상세 하단 | 배너형 | `work_detail` |
| Insight 상세 하단 | 배너형 | `insight_detail` |

**이 5곳 외에 CTA를 추가하지 않는다.** 추가하려면 반드시 이벤트 측정 설계와 함께 제안한다.

## 4. 공통 상태 화면

```
[404]                              [빈 상태 (목록 0건)]
┌──────────────────────┐           ┌──────────────────────┐
│                      │           │   (일러스트/아이콘)  │
│   페이지를 찾을 수   │           │  준비 중인 콘텐츠가  │
│   없습니다           │           │  곧 공개됩니다       │
│   [홈으로] [문의하기]│           │  [문의하기 →]        │
└──────────────────────┘           └──────────────────────┘
```

> **빈 상태는 필수 구현.** 오픈 시점에 Work가 0건일 가능성이 높다(Q4). 빈 상태에서도 문의 전환 경로를 끊지 않는다.

## 5. 반응형 브레이크포인트

| 구간 | 기준 | 비고 |
|---|---|---|
| 모바일 | < 768px | 1열, 인터랙션 일부 비활성(§P-01 참조) |
| 태블릿 | 768 ~ 1023px | 2열 |
| 데스크톱 | ≥ 1024px | 콘텐츠 최대폭 1200px 중앙 정렬 |

**전 화면 공통**: `prefers-reduced-motion` 시 모든 스크롤 인터랙션을 페이드 1종으로 대체.
