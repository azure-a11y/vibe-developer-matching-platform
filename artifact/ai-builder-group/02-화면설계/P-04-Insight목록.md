## 카테고리 4종 (기획서 §4.3 — 클라이언트 승인 대기 🟡)

| 카테고리 | URL | 존재 이유 |
|---|---|---|
| 일하는 방식 | `/insight/how-we-work` | 핵심 소구점 직결 |
| AI 활용 공유회 | `/insight/ai-playbook` | "AI 최적화 인재" 증명 |
| 발주 가이드 | `/insight/client-guide` | 검색 유입용 ("조심해야 합니다" 류) |
| 빌더 노트 | `/insight/builder-note` | 빌더 자산화 → 프로필 연결 |

## 스펙

| 항목 | 내용 |
|---|---|
| 카테고리 전환 | **URL 경로 변경** (`/insight/[category]`) — 쿼리가 아닌 경로. 카테고리 페이지도 색인 대상 |
| 리스트 인터랙션 | ⛔ 등장 애니메이션 없음 (읽으러 온 사람을 막지 않는다). hover 배경 변화만 |
| 작성자 표기 | 운영팀 or 빌더명. 빌더명 클릭 → 프로필 (2차, 1차는 텍스트만) |
| 페이지네이션 | "더 보기" 버튼 |
| 빈 카테고리 | "이 주제의 첫 글을 준비 중입니다" + 다른 카테고리 유도 |
| SEO | 카테고리별 고유 title·description. 각 카테고리 H1은 카테고리명으로 교체 |
| 이벤트 | 카테고리 전환은 URL로 자동 추적. 별도 클릭 이벤트 불필요 |

## 모바일

- 카테고리 네비 → 상단 가로 스크롤 칩.
- 리스트 카드: 썸네일 좌측 소형 배치 1열.
