# P-01 홈 `/`

| | |
|---|---|
| 우선순위 | **P0** |
| 색인 | ✅ (사이트 대표 페이지) |

| 성공 조건 | **섹션마다 다른 인터랙션. 인접 섹션 중복 금지. S4·S7은 의도적 정지.** |

## S1. Hero

```
┌────────────────────────────────────────────────────────────────┐
│ (GNB — 투명 상태)                                              │
│                                                                │
│                                                                │
│        바이브 코딩으로,                                        │
│        외주를 해드립니다                    ← H1 (2줄 분할)    │
│                                                                │
│        AI 시대에는 AI에 최적화된 개발자가 필요합니다.          │
│        검증된 빌더가 당신의 서비스에 맞게 만듭니다.            │
│                                                                │
│        ┌──────────────────┐                                    │
│        │  프로젝트 문의 → │  ← 유일한 Hero CTA                │
│        └──────────────────┘                                    │
│                                                                │
│                                    ░░░ 배경: 그라디언트 ░░░    │
│                                    (느린 이동, 코들 색감 참고) │
│                                        ↓ 스크롤 유도 표시      │
└────────────────────────────────────────────────────────────────┘
```

- **인터랙션**: 헤드라인 → 서브카피 → CTA 순 **스태거 등장** (0.1s 간격) + 배경 그라디언트 느린 이동
- 카피 규칙: 가격 언급 ⛔ / 교육 언급 ⛔ / "외주를 해드립니다"가 첫 문장
- 이벤트: `cta_click {location: "hero"}`

## S2. 문제 제기

```
┌────────────────────────────────────────────────────────────────┐
│  ◀ 좌측: 고정(Fixed) 영역 ▶      ◀ 우측: 스크롤 따라 교체 ▶   │
│                                                                │
│  요즘 바이브 코딩 외주,          ┌────────────────────────┐    │
│  이런 곳은 조심하세요            │ ① 포트폴리오 수백 개가 │    │
│                                  │   전부 목업인 업체     │    │
│  (스크롤 진행에 따라             ├────────────────────────┤    │
│   우측 카드가 순서대로           │ ② 전 섹션이 똑같은     │    │
│   하이라이트됨)                  │   애니메이션인 사이트  │    │
│                                  ├────────────────────────┤    │
│                                  │ ③ 싼 가격만 내세우는   │    │
│                                  │   반값 외주            │    │
│                                  └────────────────────────┘    │
└────────────────────────────────────────────────────────────────┘
```

- **인터랙션**: **콘텐츠 Fixed + 스크롤 연동** — 좌측 헤드라인 고정, 우측 카드가 스크롤 위치에 따라 하나씩 활성화
- 설계 의도: 발주자의 불안을 우리가 먼저 말한다 → 다음 섹션(우리 방식)의 설득력을 만드는 빌드업
- 모바일: Fixed 해제, 세로 나열 + 순차 페이드

## S3. 일하는 방식 ★핵심 소구

```
┌────────────────────────────────────────────────────────────────┐
│   그래서 우리는, 일하는 방식이 다릅니다                        │
│                                                                │
│   ●───────────○───────────○───────────○   ← 진행 인디케이터   │
│                                                                │
│   ┌──────┐   ┌──────┐   ┌──────┐   ┌──────┐                    │
│   │ 01   │   │ 02   │   │ 03   │   │ 04   │ ──▶ 가로 스크롤   │
│   │ 기획 │   │디자인│   │ 개발 │   │ 검수 │     (세로 스크롤  │
│   │      │   │(목업)│   │      │   │      │      과 연동)     │
│   └──────┘   └──────┘   └──────┘   └──────┘                    │
│   각 카드: 단계 설명 2줄 + 산출물 아이콘                       │
└────────────────────────────────────────────────────────────────┘
```

- **인터랙션**: 섹션 진입 시 화면 고정 → **세로 스크롤이 가로 이동으로 치환** (4단계 통과 후 해제)
- 모바일: 가로 스와이프 캐러셀로 대체
- 콘텐츠 근거: 기획→디자인(목업)→개발 3단계 + 검수 (수업 가이드라인)
