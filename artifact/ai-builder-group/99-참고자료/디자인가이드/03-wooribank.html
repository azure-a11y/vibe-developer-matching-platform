우리은행
블루 그라데이션 시네마틱

앞의 두 사례와 정반대입니다. 대형 풀블리드 영상/이미지 위에 흰 글씨를 얹는 시네마틱 구성이 기본이고, 브랜드 블루(#1572ED)에서 네이비(#000A75), 시안(#00D0FF)까지 넓은 블루 스펙트럼을 그라데이션으로 씁니다. 텍스트 그레이가 순수 회색이 아니라 푸른기가 도는 쿨 그레이(#656D77 계열)인 것도 특징.

01

디자인 무드

"규모와 신뢰". 큰 화면, 큰 글자, 깊은 블루.

Tone

블루 스펙트럼

단일 블루가 아니라 네이비(#000A75) → 블루(#1572ED) → 시안(#00D0FF)의 폭넓은 범위를 그라데이션으로 이어 씁니다.

Layout

풀블리드 시네마

히어로는 화면을 가득 채우는 영상. 그 위에 흰 텍스트와 PAUSE 컨트롤만 올립니다.

Type

초대형 숫자

160px / 108px 같은 극단적 크기로 수치·연혁을 표현. 전용서체 Wooridaum을 이 자리에만 씁니다.

Surface

부드러운 그림자

앞 두 사례와 달리 0 16px 20px rgba(0,0,0,.06)의 넓고 옅은 그림자로 카드를 띄웁니다.

02

컬러 시스템

스와치를 클릭하면 HEX가 복사됩니다.

Blue Spectrum

Cool Gray — 순수 회색이 아닌 청회색

✓ Do

  • 회색은 반드시 청회색 계열(#656D77)로. 중립 회색(#888)을 섞으면 톤이 깨진다.
  • 이미지 위 텍스트는 흰색 + rgba(0,0,0,.5) 딤 레이어를 함께.
  • 블루 그라데이션은 인접한 색끼리(예: #014CFF → #1572ED) 연결.

✗ Don't

  • 시안(#00D0FF) 위에 흰 텍스트를 불투명하게 얹기 — 대비 부족.
  • 블루를 본문 텍스트 색으로 사용.
  • 네이비와 시안을 인접 배치 없이 급격히 붙이기.

Contrast

딤 레이어

영상 위 텍스트에는 rgba(0,0,0,.5) 오버레이를 깔아 명도 대비를 확보합니다.

07

체크리스트

  1. 히어로는 풀블리드 영상/이미지 + 흰 텍스트 + 딤 레이어가 기본형.
  2. 회색은 전부 청회색 계열(#0A0C0E / #1F2428 / #535A63 / #656D77) 4단계로만.
  3. 버튼 라운드는 높이에 비례: 작으면 24px, 크면 30px, 원형 컨트롤은 40px.
  4. 카드 그림자는 0 16px 20px rgba(0,0,0,.06) 하나로 통일.
  5. 대형 카피에는 weight 300을 과감히 사용해 여백감을 만든다.
  6. 자간은 크기에 비례해 −0.02em 고정 비율로.
  7. Skip Nav와 영상 PAUSE 컨트롤을 반드시 포함.
