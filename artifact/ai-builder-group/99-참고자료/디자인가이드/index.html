디자인 가이드 추출

각 사이트를 실제 브라우저로 열어 렌더링된 computed style을 전수 스캔했습니다. 추측이 아니라 실측값 — CSS 변수, 사용 빈도 상위 색상, 폰트·크기·굵기·자간·행간, 라운드·그림자·보더, 버튼/카드 실제 스펙을 뽑아 사이트별 가이드 문서로 정리했습니다.

실측 기반 컬러 클릭 → HEX 복사 복붙용 CSS 토큰 포함
01

가이드 문서

카드를 클릭하면 해당 사이트의 전체 디자인 가이드로 이동합니다.

01 — FINANCIAL
카카오뱅크

순수 흑백 뼈대 + 노랑 포인트. 그림자·보더 0건의 완전 플랫. 19단계 그레이 스케일.

#FFE300PretendardFlatPill 50px
02 — EDITORIAL
카카오뱅크 앤써

파스텔 카드 매거진. 반전 네이밍 토큰(--black100 = #fff)으로 다크모드를 값 교체만으로 전환.

#FFC801Dark ModePastelPill 99px
03 — CORPORATE
우리은행

풀블리드 영상 시네마틱. 네이비→시안 블루 스펙트럼, 청회색 텍스트, 전용서체 Wooridaum.

공통점 1

전부 알약 버튼

5개 사이트 모두 버튼이 완전 알약형입니다(50 / 99 / 30 / 500 / 9999px). 각진 버튼을 쓰는 곳이 하나도 없습니다.

공통점 2

Pretendard 지배

미래엔(SUIT)을 제외한 4곳이 Pretendard 기반. 한국 웹 표준 서체로 굳어졌습니다.

공통점 3

음수 자간

코들을 제외한 4곳이 −0.01~0.03em의 음수 자간을 씁니다. 한글 조판을 조이는 것이 기본값.

갈림길 1

그림자 유무

카카오뱅크 계열은 그림자 0건의 플랫, 나머지 3곳은 넓고 옅은 그림자로 깊이를 만듭니다.

갈림길 2

본문 굵기

미래엔이 700~800으로 압도적으로 굵고, 우리은행은 400으로 가장 얇습니다.

갈림길 3

배경 시작점

순백에서 시작하는 곳은 카카오뱅크·코들뿐. 나머지는 #F6F6F6·#F5F7FD·#F8F9FA 같은 옅은 톤에서 시작합니다.

03

이 문서의 색감 — AI빌더스쿨

요청하신 색감 참고 사이트(builderschool.ai)의 팔레트를 가이드 문서 자체의 껍데기에 적용했습니다. 페이퍼 베이지 + 잉크 블랙 + 라임 액센트 조합입니다.

Font

Pretendard + JetBrains Mono

본문은 Pretendard, 라벨·수치·메타 정보는 모노스페이스로 대비를 줍니다. 이 문서도 같은 조합입니다.

Shape

999px · 24px · 18px

알약 태그와 크게 둥근 카드. 원형(50%) 요소도 자주 씁니다.

Rule

라임은 극소량

#D8FF3D는 배경 대비가 강해서 넓게 쓰면 눈이 아픕니다. 하이라이트·배지·1개 CTA에만.

04

사용법 · 파일 구조

Tip

색상 스와치 클릭 → HEX 복사

모든 가이드 페이지의 색상 칩은 클릭하면 클립보드에 HEX가 복사됩니다. COPIED 배지가 잠깐 표시됩니다.

Tip

마지막 섹션 = 복붙용 토큰

각 페이지 맨 아래 복사용 CSS 토큰 블록을 그대로 프로젝트에 붙여넣으면 그 사이트의 룩앤필로 바로 시작할 수 있습니다.

디자인가이드/
├─ index.html                  ← 지금 보는 페이지 (허브 · 비교표)
├─ 01-kakaobank.html           카카오뱅크
├─ 02-kakaobank-answer.html    카카오뱅크 앤써
├─ 03-wooribank.html           우리은행
├─ 04-miraen-aidt.html         미래엔 AIDT
├─ 05-codle.html               코들
└─ assets/
   ├─ guide.css                공통 문서 스타일 (빌더스쿨 색감)
   └─ copy.js                  스와치 클릭 복사

수집 방법 — 각 사이트를 브라우저로 열어 document.querySelectorAll('body *') 전체를 순회하며 getComputedStyle로 색·폰트·크기·굵기·자간·행간·라운드·그림자·보더를 집계하고, 사용 빈도 상위 값과 :root CSS 변수를 함께 추출했습니다. 표에 적힌 px 값은 모두 실제 렌더링 결과입니다.
