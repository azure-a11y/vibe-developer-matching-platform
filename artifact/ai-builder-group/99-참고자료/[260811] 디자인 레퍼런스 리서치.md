## 1. 진단 — 현재 목업이 왜 AI가 만든 것 같은가

레퍼런스를 보기 전에, 고칠 대상을 명확히 한다. 잘 만든 사이트들과 비교했을 때 현재 목업의 "딸깍 신호"는 인터랙션이 아니라 **디테일 밀도**에 있다.

| # | 신호 | 현재 목업 | 사람이 만든 사이트 |
|---|---|---|---|
| 1 | **완벽한 대칭 그리드** | 모든 카드가 3열 균등, 모든 섹션이 중앙 정렬 | 어딘가는 그리드를 깬다 — 4:8 분할, 삐져나온 이미지, 좌우 비대칭 |
| 2 | **콘텐츠가 전부 같은 길이** | 카드 설명이 전부 1~2줄, 제목이 전부 비슷한 글자수 | 실데이터는 들쭉날쭉하다. 그 들쭉날쭉함이 "진짜"로 보이게 한다 |
| 3 | **플레이스홀더 그라디언트** | 모든 썸네일이 같은 방사형 그라디언트 | **실제 스크린샷·실물 사진·목업 프레임** — 에셋이 퀄리티의 전부 |
| 4 | **수치·실명·로고의 부재** | "빌더 A", "프로젝트명" | 고객사 로고 30개, "9년", "제안서 작성 시간 단축" 같은 **구체 수치** (똑개 실측) |
| 5 | **타이포 위계가 2단계뿐** | 큰 제목 / 회색 본문의 반복 | 아이브로우(모노 소문자) → 대제목 → 리드문 → 본문 → 캡션, **5단계 위계** |
| 6 | **모든 여백이 균일** | 섹션 패딩 92px 반복 | 붙일 곳은 확 붙이고(제목-리드 8px), 띄울 곳은 확 띄운다(섹션 간 160px+) |
| 7 | **이징이 전부 동일** | 하나의 cubic-bezier 재사용 | 등장은 expo-out, 퍼짐은 커스텀, 호버는 짧게 — **동작마다 다른 곡선** |
| 8 | **한글 타이포 디테일 없음** | 자간 일괄 -0.01em | 제목은 -0.04~-0.06em 강하게, 본문은 느슨하게, **숫자는 모노폰트 분리** |

→ **결론: 인터랙션 종류는 이미 요구사항을 충족한다. v2에서 고칠 것은 ①실감나는 콘텐츠(에셋·수치·실명) ②그리드 붕괴 ③타이포·여백 리듬이다.**

## 2. 국내 레퍼런스 — 레이아웃·소재·카피 톤

### 2.1 똑똑한개발자 — toktokhan.dev ★클라이언트 1순위 레퍼런스 (실측 분석 완료)

**메인 페이지 실제 구조** (2026.08 확인):

| 순서 | 섹션 | 훔쳐올 것 |
|---|---|---|
| 1 | Hero "AI 도입을 넘어 일하는 방식을 바꿉니다" + **포트폴리오 15개 카루셀** | 히어로에 실물 결과물을 흘려보내는 방식 — 말보다 실물. **우리 S1 배경에 적용 후보** |
| 2 | 3단계 프로세스 (설계→운영→검증) | 프로세스를 동사로 명명. 우리 S3와 동일 문법 |
| 3 | 차별화 4카드 ("9년 경험" 등) | **카드마다 근거 수치가 박혀 있음** — 형용사가 아니라 숫자 |
| 4 | "우리 조직에 먼저 적용해봤어요" + 지표 4개 | ★이 카피 톤. 자랑이 아니라 실험 보고. **우리 S4에 이식할 화법** |
| 5 | 고객사 로고 30+ 무한 카루셀 | 신뢰 섹션의 정석. 우리는 Q4 확정 후 적용 |
| 6 | 최종 CTA + FAQ 링크 | CTA 직전에 FAQ를 두는 배치 (우리 S9→S10 순서와 동일) |
| Footer | 서비스/회사/자체서비스/법률/사업자정보 6그룹 | **푸터 정보 밀도** — 우리 목업 푸터가 빈약한 이유가 여기서 보임 |

- FAQ URL 분기(`/faq/aiax`↔`/faq/it`), pluug 연동 폼도 이 사이트에서 실물 확인할 것.
- Work 상세 페이지의 **슬러그 구조·본문 서술 방식**(문제→해결→결과)도 대조 대상.

## 5. 목업 v2 반영 체크리스트 (진단 §1 대응)

- [ ] **에셋 교체** — 그라디언트 플레이스홀더 → 실제 프로젝트 스크린샷을 브라우저 프레임에 넣은 목업 이미지 (§1-3)
- [ ] **그리드 붕괴 1곳 이상** — S6를 plus-ex식 대소 혼합(첫 카드 2배)으로 (§1-1)
- [ ] **콘텐츠 길이 불균일화** — 카드 설명을 일부러 1줄/3줄 섞기 (§1-2)
- [ ] **푸터 증량** — 똑개식 6그룹 (사업자정보 자리 포함) (§1-4)
- [ ] **타이포 위계 5단계** — 아이브로우/대제목(-0.05em)/리드문/본문/모노 캡션 (§1-5)
- [ ] **여백 리듬 파괴** — 섹션별 패딩 차등 (S4 압축, S1·S10 확대) (§1-6)
- [ ] **이징 3종 분리** — 등장 expo-out / 퍼짐 커스텀 / 호버 150ms (§1-7)
- [ ] **숫자 모노폰트 분리** — 날짜·기간·수치 전부 JetBrains Mono로 (§1-8)
- [ ] 커서 디테일 — Work 카드 hover 시 "View →" 커서 추종 (cuberto 참고, 과하면 제외)
