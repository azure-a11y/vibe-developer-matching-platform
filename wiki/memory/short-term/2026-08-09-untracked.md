# 결정적-콘텐츠-검수-게이트 글은 그대로 두고 더 이상 언급하지 않는다

## 무엇

`content/posts/결정적-콘텐츠-검수-게이트.md` ("검수 게이트에 LLM을 넣지 않는 이유")는 8/4 세션에서
작성 완료된 `in_review` 상태 글. `pnpm audit:content` 100점, 발행 가능. 하지만 git에는 여전히
untracked 상태로 남아 있음. 사용자에게 "8/4 미완료 건"이라고 보고했더니, 사용자는 이 글을 자기가
중단시켜서 안 써진 것으로 기억하고 있었음 — 실제로는 완성돼 있었다는 걸 확인시켜준 뒤,
사용자가 "그냥 둬. 이 글에 대해서는 더 이상 알리지 말라"고 명시적으로 지시함.

## 왜

사용자가 이 글의 존재/상태를 이미 인지했고, 커밋·발행·수정 등 어떤 조치도 원하지 않음.
work-log 훅이나 git status 점검 중 이 파일이 다시 걸려도 굳이 다시 보고할 필요 없음 — 이미
확인된 사안을 반복해서 알리는 건 노이즈.

## 영향

- 앞으로 세션에서 `git status`나 work-log 요약에 이 파일이 untracked/in_review로 다시 나타나도
  **먼저 언급하지 말 것**. 사용자가 먼저 물어보면 답한다.
- 이 글을 커밋하거나, 발행하거나, 내용을 고치는 등 어떤 조치도 사용자 요청 없이 하지 않는다.
- **다른 글**(새로 작성되거나 다른 이유로 미완료/미커밋인 글)에 대해서는 평소대로 정상 보고한다.
  이 예외는 이 파일 하나에만 국한됨.
